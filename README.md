# Journex – AI Agentic Accounting System for Automated Accounting Document Processing

## 1. Project Introduction

Journex is an AI Agentic Accounting System developed as part of the Project I. The project aims to automate accounting document processing and reduce manual work in accounting tasks.

The system uses four specialised agents to handle different accounting processes:

* **Document Processing Agent** – Collects financial documents and extracts important information.
* **Verification Agent** – Checks the extracted information and verifies calculations.
* **Accounting Agent** – Classifies transactions and prepares debit and credit journal entries.
* **Error Detection Agent** – Reviews journal entries and identifies possible accounting errors.

The project focuses on designing and developing a system that allows these agents to work together to support accounting document processing.

During Project I, research, system analysis, system design and a preliminary working prototype were completed. Further development and complete integration of the four agents will continue in Project II.
